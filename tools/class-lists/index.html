Import / Export

CSV-Vorlage: eine Zeile pro Schüler. Erlaubte Trennzeichen: Semikolon, Komma oder Tab.

class_name;student_name 9a;Anna M. 9a;Ben K. 10b;Carla S.
CSV ist Klartext. Beim Export stehen die Namen unverschlüsselt in der Datei. Für eine Sicherung oder Geräteübertragung ist deshalb das verschlüsselte Backup die bessere Wahl.

Datensparsam: Wenn möglich nur Vorname + Initial verwenden, z. B. „Anna M.“ statt vollständigem Namen.
